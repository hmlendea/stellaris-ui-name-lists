## 🔎 What This Document Covers

This document describes how Universum Infinitum: Name Lists at https://github.com/hmlendea/stellaris-ui-name-lists handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 🏠 Self-Hosted Deployments

This project is a Stellaris modification distributed as a data-only mod. Users download and install the mod locally into their Stellaris game directory. The project maintainers do not operate any service, server, or hosted instance. All data processing occurs on the user's local machine within the Stellaris game client. Instance operators (users who install the mod) control their local Stellaris installation, including any logs, save files, or configuration generated by the game. No data is transmitted from the mod to the project maintainers or any external service.

## 📥 Data We Handle

### Data Provided to the Application

No personal data is requested, collected, or provided to the application. The mod provides only name list definitions for empire creation in Stellaris.

### Data Generated or Collected by the Application

No personal data is generated or collected automatically by the mod. The mod consists solely of static data files (name lists) that are read by the Stellaris game engine during empire creation.

### Data Received from Integrations

No personal data is received from integrations or third parties. The mod has no network connectivity, API integrations, or external data sources.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- Providing name list options during Stellaris empire creation — Static name list definitions (no personal data involved)

## 🗄️ Storage, Retention, and Deletion

The mod consists of static data files installed in the user's Stellaris mod directory. No personal data is stored by the mod. Any data stored by the Stellaris game client (save games, logs, configuration) is controlled entirely by the user and the game client, not by this mod. Users may delete the mod at any time by removing its files from the Stellaris mod directory.

## 🔗 External Processing and Integrations

The application has no built-in external data transfer, integrations, or network connectivity. The mod is a collection of static data files read locally by the Stellaris game engine.

| Service or integration | Purpose | Data involved | Configuration or documentation |
|-----------------------|---------|---------------|--------------------------------|
| None | Not applicable | Not applicable | Not applicable |

## 🛡️ Data Protection and Security

The mod contains no executable code, network functionality, or data processing capabilities. It consists exclusively of static text files defining name lists for Stellaris. No personal data is processed, transmitted, or stored by the mod. Security of the user's Stellaris installation, save files, and any game-generated data is the responsibility of the user and the Stellaris game client. The project maintainers distribute the mod through GitHub Releases, Steam Workshop, Nexus Mods, and Paradox Mods; users should verify downloads through those platforms' integrity mechanisms.
