# Configuration

## Configuration Sources

The build pipeline uses multiple configuration sources with defined precedence:

| Priority | Source | Scope | Example |
|----------|--------|-------|---------|
| 1 | Environment variables | Runtime overrides | `STELLARIS_VERSION=v4.4.*` |
| 2 | Script constants | Hard-coded defaults | `MOD_ID="ui_name_lists"` |
| 3 | Path configuration | `scripts/common/paths.sh` | `OUTPUT_DIR="$REPO_DIR/out/ui-name-lists"` |
| 4 | Composition variables | `scripts/build.sh` | `HUMAN_EXTENDED_NAMELISTS="..."` |
| 5 | CI/CD secrets | GitHub Actions | `STEAM_USERNAME` |

## Environment Variables

### Build-Time

| Variable | Default | Description |
|----------|---------|-------------|
| `STELLARIS_VERSION` | `v4.3.*` | Supported Stellaris version in descriptor.mod |
| `MOD_NAME` | `Universum Infinitum: Name Lists` | Mod display name |
| `MOD_ID` | `ui_name_lists` | Mod internal ID |
| `VERSION` | `dev` / Git tag | Mod version for release artefacts |
| `BUILDER_VERSION` | `v1.2.3` | StellarisNameListGenerator version |

### CI/CD Secrets (GitHub Actions)

| Secret | Workflow | Purpose |
|--------|----------|---------|
| `STEAM_USERNAME` | steam-workshop.yml | Steam account for upload |
| `STEAM_PASSWORD` | steam-workshop.yml | Steam account password |
| `STEAM_2FA_SEED` | steam-workshop.yml | Steam 2FA shared secret |
| `NEXUSMODS_API_KEY` | nexus-mods.yml | Nexus Mods API key |

## Configuration Files

### `scripts/common/paths.sh`

```bash
# Repository root
REPO_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"

# Key directories
SCRIPTS_DIR="$REPO_DIR/scripts"
BUILD_DIR="$REPO_DIR/build"
OUTPUT_DIR="$REPO_DIR/out/ui-name-lists"
MOD_BUILDER_DIRECTORY="$REPO_DIR/.builder"
CACHE_DIR="$REPO_DIR/.cache"

# Source directories
NAME_LISTS_DIR="$REPO_DIR/name-lists"
```

**Modification**: Edit paths if repository structure changes.

### `scripts/update-builder.sh`

```bash
BUILDER_VERSION="v1.2.3"
BUILDER_URL="https://github.com/hmlendea/stellaris-name-list-generator/releases/download/$BUILDER_VERSION/StellarisNameListGenerator-linux-x64.zip"
```

**Modification**: Update `BUILDER_VERSION` when new generator released.

### `scripts/build.sh` (Configuration Section)

```bash
# Mod metadata
MOD_ID="ui_name_lists"
MOD_NAME="Universum Infinitum: Name Lists"
STELLARIS_VERSION="v4.3.*"

# Version detection
if [[ -n "$GITHUB_REF_NAME" && "$GITHUB_REF_NAME" =~ ^v[0-9]+\.[0-9]+\.[0-9]+$ ]]; then
    VERSION="$GITHUB_REF_NAME"
else
    VERSION="dev"
fi
```

**Modification**: Update `STELLARIS_VERSION` for new Stellaris major versions.

## Composition Variables

Defined in `scripts/build.sh`, these map output name lists to source files.

### Pattern

```bash
<COMPOSITION_NAME>_NAMELISTS="path/to/source1.xml path/to/source2.xml ..."
```

### Categories

| Prefix | Output Type | Example |
|--------|-------------|---------|
| `AFRICAN_`, `ARABIC_`, etc. | Human cultural variants | `AFRICAN_NAMELISTS` |
| `HUMAN_` | Human aggregate lists | `HUMAN_EXTENDED_NAMELISTS` |
| `UI_` | Species UI lists | `UI_ART1_NAMELISTS` |
| `EXTRA_` | Extra variants | `EXTRA_HUM1_NAMELISTS` |
| `<FRANCHISE>_` | Media-specific | `STARWARS_HUMAN_NAMELISTS` |

### Adding New Composition

1. Define variable with source paths
2. Add to `COMPOSITIONS` array in `main()`
3. Call `build()` with id, display name, variable

```bash
NEW_COMPOSITION_NAMELISTS="name-lists/real/new/culture.xml name-lists/media/franchise/name.xml"

COMPOSITIONS=(
    # ... existing ...
    "new_id|New Display Name|NEW_COMPOSITION_NAMELISTS"
)
```

## Stellaris Mod Descriptor Configuration

**Output**: `out/ui-name-lists/descriptor.mod`

```ini
name="Universum Infinitum: Name Lists"
supported_version="v4.3.*"
tags={
    "Name List"
}
description="Provides numerous detailed name lists for empire creation..."
picture="thumbnail.png"
```

**Generated by**: `generate_mod_descriptor()` in `build.sh`

**Modifiable fields**:
- `name` → `MOD_NAME`
- `supported_version` → `STELLARIS_VERSION`
- `description` → Edit function directly
- `picture` → Replace `thumbnail.png` in repo root

## Validation Configuration

**File**: `scripts/validate-data.sh`

### Structural Rules (Hard-coded)

| Rule | Pattern | Configurable? |
|------|---------|---------------|
| Double tags | `<NameList>.*<NameList>` | No |
| Empty Values | `<Values>\s*</Values>` | No |
| Empty Value | `<Value>\s*</Value>` | No |
| Multiple Characters | `<Characters>.*<Characters>` | No |
| Url in Values | `<Values>.*<Url>` | No |
| Name outside NameGroup | Complex | No |
| Malformed nesting | Various | No |

### Semantic Rules

| Rule | Configurable? |
|------|---------------|
| URL reachability | Cache TTL (7 days, hard-coded) |
| HTTP timeout | 10 seconds (hard-coded) |

**To modify**: Edit `validate-data.sh` functions directly.

## Cache Configuration

### `.builder/` (Binary Cache)

- **Location**: `$REPO_DIR/.builder/`
- **Content**: `StellarisNameListGenerator` binary
- **Invalidation**: Delete directory or update `BUILDER_VERSION`
- **Size**: ~50 MB

### `.cache/` (URL Validation Cache)

- **Location**: `$REPO_DIR/.cache/`
- **Content**: `url_<sha256>` files with `OK`/`FAIL`
- **TTL**: 7 days (hard-coded in `check_url()`)
- **Invalidation**: Delete directory or wait for expiry
- **Size**: ~1 KB per unique URL

## CI/CD Configuration

### `.github/workflows/build.yml`

```yaml
on:
  push:
    branches: [master]
  pull_request:
    branches: [master]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - run: ./scripts/validate-data.sh

  build:
    needs: validate
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - run: ./scripts/build.sh
      - uses: actions/upload-artifact@v4
        with:
          name: ui-name-lists
          path: release/ui-name-lists_*.zip
```

### `.github/workflows/steam-workshop.yml`

```yaml
on:
  push:
    tags: ['v*.*.*']

env:
  STEAM_USERNAME: ${{ secrets.STEAM_USERNAME }}
  STEAM_PASSWORD: ${{ secrets.STEAM_PASSWORD }}
  STEAM_2FA_SEED: ${{ secrets.STEAM_2FA_SEED }}
```

### `.github/workflows/nexus-mods.yml`

```yaml
on:
  push:
    tags: ['v*.*.*']
  workflow_dispatch:
    inputs:
      tag:
        required: true

env:
  NEXUSMODS_API_KEY: ${{ secrets.NEXUSMODS_API_KEY }}
```

## Local Development Overrides

### Temporary Configuration

```bash
# Override Stellaris version for testing
STELLARIS_VERSION="v4.4.*" ./scripts/build.sh

# Use specific builder version
BUILDER_VERSION="v1.2.4" ./scripts/update-builder.sh

# Skip validation (not recommended)
# Edit build.sh to comment out validate-data.sh call
```

### Persistent Local Config

Create `scripts/local-config.sh` (gitignored):

```bash
# scripts/local-config.sh
export STELLARIS_VERSION="v4.4.*"
export BUILDER_VERSION="v1.2.4"
```

Source in shell:
```bash
source scripts/local-config.sh
./scripts/build.sh
```

## Configuration Validation

### Pre-Build Checks

```bash
# Verify required commands
command -v curl >/dev/null || { echo "curl required"; exit 1; }
command -v wget >/dev/null || { echo "wget required"; exit 1; }
command -v unzip >/dev/null || { echo "unzip required"; exit 1; }

# Verify directories
[[ -d "$NAME_LISTS_DIR" ]] || { echo "name-lists/ missing"; exit 1; }
```

### Post-Build Verification

```bash
# Verify output structure
[[ -f "$OUTPUT_DIR/descriptor.mod" ]] || { echo "descriptor.mod missing"; exit 1; }
[[ -f "$OUTPUT_DIR/thumbnail.png" ]] || { echo "thumbnail.png missing"; exit 1; }
[[ -d "$OUTPUT_DIR/common/name_lists" ]] || { echo "name_lists dir missing"; exit 1; }
[[ -d "$OUTPUT_DIR/localisation/english" ]] || { echo "localisation dir missing"; exit 1; }

# Verify name list count
COUNT=$(grep -c "name_list = {" "$OUTPUT_DIR/common/name_lists/00_ui_name_lists.txt")
[[ $COUNT -gt 40 ]] || { echo "Too few name lists: $COUNT"; exit 1; }
```
